# Newberry Library sweep (28 Oct 2026)

Result: 3 candidate rows in candidates.json, all weak. The Newberry holds very little cipher text in its catalogue
records; its cipher-related holdings are mostly printed books on cryptography. Method, queries and counts are in
coverage.md. Scripts: primo.py (Primo VE JSON search, guest JWT), carli.py (CONTENTdm dmQuery), ndc.py (Digital
Collections item pages).

## Candidates (best first)
1. Case MS 7A 4: Burr's autograph letter "largely in cypher" to Wilkinson, 1806 (access: archive). Probably a copy of
   the already-published 22 July 1806 cipher letter; the key explanation (Graff 4668) is digitised. Importance 3.
2. Case MS 5017 characters-table page (access: online, nby_dig/2714): key plus two sample lines, a key lead rather than
   unsolved text; other pages of the volume unchecked.
3. Ayer MS 1297, Apuntes sobre Filipinas ca. 1853: "shorthand or code" sections and a tipped-in leaf. Importance 1.

## Key leads and non-candidates
- Wilkinson memorandum explaining the Burr-Wilkinson cypher: VAULT folio Graff 4668, digitised
  (https://collections.carli.illinois.edu/digital/collection/nby_graff/id/16326). Useful for the LoC Burr/Graham and
  Wilkinson entries already in the catalogue (482, 761).
- Burr papers, Ayer MS 124 (photostats of LoC material): "Some letters written in numerical code, with translations of
  the code supplied above". Deciphered, so excluded.
- Coach painter's cipher book (Wing MS ZW 743 .L 432, 1763): monograms, not secret writing.
- Willoughby, Cryptography and ciphers notebook (ca. 1935, Midwest MS): notes and examples, a draft for a Bible cryptogram book.
- Nostradamus cipher typescript (1960s-70s); Pepys diary (printed): out of scope.
- Woolson family papers (1889-1910) matched "cipher" but the matching text was not located; unchecked.
