# NARA bulk-scan triage, slice G: RG 242 (captured German records) and RG 94 (Adjutant General) (27 Oct 2026)

Brief: `research/nara_reels/TRIAGE_BRIEF.md` and `research/archive_sweep_2026-10/BRIEF.md`. Scope: classical/hand ciphers
and codes 1350-1950, German hand systems included, machine traffic (Enigma, Lorenz, Hagelin) out. Every row was checked
against catalogue.json 628-703, the READMEs of `nara_triage_a`-`_f`, `nara_military`, `nara_state`, `nara_catalog`, and
run through `known.py`. No bulk_scan.py process was started, restarted or stopped. Nothing committed.

Output: `candidates.json` (4 rows, generated by `rows.py`).

Scripts here:
- `show.py <naId> info|frame a [b]|grep <rx>`: cached OCR of an item (fetch with `nara_reels/reels.py fetch`)
- `ic.py <naId> a b`: letter statistics of the five-letter groups on frames a..b (tells transposition from Enigma)
- `dw1939.py`: the T405 roll 9 test: the 25.2.1939 Luftgauschlüssel applied to the 1939 exercise message
- `numscan.py <rg> [path] [digits]`: ranks numeric frame hits by number-group runs plus radio/cipher vocabulary,
  minus table vocabulary (`numscan_242.tsv`, `numscan_94.tsv`)
- `filter94.py`: drops RG 94 service/pension/medical card series by ancestor → `slice94.jsonl` (regenerable, git-ignore)

## Best leads

1. **Flugabwehrkommando Schwarzwald, Luftwaffe Flak radio messages, April-June 1940 (T405 roll 9, NAID 332033680).**
   About 70 Funkspruch forms in five-letter groups, mostly multi-part messages ('1.Tl' ... '5.Tl') of 160-250 letters. The
   group letters keep German frequencies with X separators (pooled IC 0.060 on OCR; Enigma frames elsewhere in RG 242 give
   0.038-0.040), so this is transposition. Frame 350 holds a key card "Annahme: Luftgauschlüssel für den 25.2.1939" (two
   transposition keys of 21 and 19, Kenngruppen) and frame 349 the exercise message of that day. Transcribed from the
   images and tested: it reads in full as a double columnar transposition (key a then b, the group holding Kenngruppe
   'fks' at position 7 removed, CH written Q): "ROEM X ERSTE FLAKREGIMENT X ZWOELF ... NAQ X MAGDEBURG X VERLEGT X
   LUFTGAUKOMMANDO X ROEM X DREI". The 1940 messages have no key and no decipherment with them; clear Fernschreiben
   on neighbouring frames are candidate cribs. Class B, solvability 3, difficulty 4.
2. **British consular cipher telegrams copied in Spain, 1939-40 (T1022 rolls 2865, 2866).** The German naval attaché Madrid
   forwarded copies of the British consul Vigo's telegrams to London (11-12 Nov 1939, on eight German steamers sailing)
   and anonymous copies of April 1940 Gibraltar/Lisbon/Lagos → British consuls Las Palmas/Tenerife telegrams, "zwecks
   möglicher Auswertung", to OKW Ausland IV and W.F.A./Chi. No decipherment filed. Class C.
3. **French consular agent Las Palmas → Marine Casablanca, April 1940** (same file, roll 2866 frames 505-507), three short
   letter-cipher telegrams. Class C.
4. **Etappendienst / Abwehr IV W.f.S. 'Scheintelegramme'** (T1022 rolls 2864, 3367, 3391): a German naval-agent hand
   system (Hapag-Lloyd commercial code + 'Kammwürfel' transposition) with several telegrams filed with their Klartext
   (key leads) and a Jan 1940 description with a worked example; two DEBEG radio telegrams to M.S. Havelland (Aug 1940)
   without clear text. Class A.

## Dead ends and blockers

- Most RG 242 radio traffic in war diaries is Enigma; told apart from hand transposition by letter IC (Enigma frames
  0.038-0.047, T405 roll 9 0.060). A Doppelkasten (digraphic) sheet would sit near 0.045-0.050 and could hide in the
  Enigma range on short OCR samples; only frames with the 'letters' flag were checked this way.
- No image of rows 2-4 viewed; read from OCR only.
- Prior art: web search for the 1939-40 Spanish intercepts of British consular telegrams found nothing (27 Oct 2026).
