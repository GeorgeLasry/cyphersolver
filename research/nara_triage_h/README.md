# NARA bulk_all triage, slice H: record groups not scanned before (27 Oct 2026)

Brief: `research/nara_reels/TRIAGE_BRIEF.md` and `research/archive_sweep_2026-10/BRIEF.md`. Input: the combined pass
`research/nara_reels/bulk_all.py` (`out/<rg>_all.jsonl`; a group is complete when `out/done_<rg>_all.txt` lists every
export file counted in `out/rg_sizes.json`). Scope: classical hand ciphers and codes 1350-1950; machine traffic and the
US services' own crypto administration (SOIs, crypto-aid receipts, cipher-device files) left out. Every row was checked
against catalogue.json (NARA ids 628-707), the READMEs of `nara_triage_a`-`_g`, `nara_military`, `nara_state`,
`nara_catalog`, and run through `known.py`. No bulk_scan.py / bulk_all.py process was started, restarted or stopped.
Nothing committed.

Output: `candidates.json`, 6 rows, generated by `rows.py`. Coverage per record group: `coverage.md` (from `coverage.py`).

## Method

1. `status.py` lists the complete groups and their hits by kind. Five passes were made as groups finished (12:35-13:20).
2. `review.py <rg> ...` prints each group compactly: every distinct `desc` title, every `phrase`/`word` snippet around
   the match with telegraph-blank boilerplate filtered out ("errors in cipher or obscure messages", Western Union
   "CLASSES OF SERVICE", "complete with ciphers"), and for `frame`/`letters`/`caps` one line per item with its two most
   solid frames (fewest words per number, lowest IC). All 236 complete groups with hits were read this way. For large
   groups the text hits were also summarised by series and match word before reading.
3. Items that looked like real cipher were fetched with `nara_reels/reels.py fetch` (10 items, one request each, 4 s
   apart) and read with `show.py <naId> <frame> [n]` / `show.py <naId> grep <regex>`; `grp5.py <naId>` lists frames
   with runs of five-letter groups. No page image was downloaded.
4. `vig1919.py` tests the 1919 AEF Siberia field message (IC, periodic Vigenere/Beaufort periods 1-15).

## Rows (ranked)

1. **AEF Siberia field message, 9 July 1919** (RG 395, M917 roll 9, frame 963). Col. Williams, Allied Mine Guard,
   Vladimirovka, to the CG AEF Siberia: 32 five-letter groups (160 letters), sent via Japanese wireless, no
   decipherment on file. IC 0.041, no periodic Vigenere/Beaufort key of period 2-15, not Playfair (JJ inside a
   digraph). The only enciphered text found in this slice that is online and complete. Importance 2, solvability 3.
2. **AEF G-2 "Records Relating to the Solution of Enemy Codes and Ciphers and the Decoding of Intercepted Messages"
   1917-18** (RG 120, naId 6582019, 26 ft, with a card index and a German code-symbol card file). The Western Front
   intercept and worksheet file (ADFGX/ADFGVX, trench codes); unread residue likely, not stated. Not digitised.
   Importance 3, solvability 1.
3. **Chicherin to Sukhanov, 4 May 1918** (RG 395, M917 roll 3, frames 350-354). Soviet telegram on routing Allied
   consular telegrams via Moscow; AEF code and cipher section "not in position to solve" its short code passages. Only
   the translation is filmed; the code text went to MID Washington. Importance 2, solvability 1.
4. **Office of Censorship "Secret Submissions" 1942-45** (RG 216, naId 1266133, 4 reels) with the card index
   (naId 1265114). Concealed-message letters with copies of the originals; code/cipher share unknown.
5. **Duisberg Code Messages** (RG 131, naId 22467079). I.G. Farben agent's code messages, OAP litigation enclosure;
   seized Chemnyco code books in the same record group are possible keys.
6. **U.S. Mint coded telegrams 1912-44** (RG 104, naId 610827) with the 1902 Treasury telegraphic code key
   (naId 1132821). Low weight, but a code set with its key.

## Dead ends worth recording

- **RG 87 Secret Service daily reports (T915), 7,743 hits.** Of 673 phrase hits, 639 are agents' own cipher
  telegrams ("sent in cypher", "received in cipher"), copied in clear in the reports; the other 34 "could not
  decipher" hits are illegible postmarks, coin dates and signatures. A grep for criminals' cipher letters (106 frames,
  `rg87_cipherletters.txt`) and full reads of 7 volumes found that each was read at the time or not copied:
  G. B. Perkins 1875 (Allegheny counterfeiters' cipher letters to N. Morse; Perkins worked out the key, copied it and
  the translations, T915-232 ff. 168-374), A. L. Drummond 1888 (Gardner opium-smuggling cipher telegrams, Ogdensburg;
  key held by Mundy, Seattle), G. W. Hazen 1905 (Dodson counterfeiters' letter, read by Deputy Black, T915-168 f. 2040),
  Memphis 1912 (H. Wardner code letter, not copied), Oklahoma 1933 (Tulsa letter "in code or Indian language", not
  copied), St. Paul 1924 (numeral-code drug letter, returned, not copied). Frame hits are indexes, calendars, serial
  numbers.
- **RG 226 OSS:** M1934 frames are Safehaven patent and statistics lists; the "code or cipher" words are dispatch-form
  boilerplate. The cipher-related desc titles (Barcelona cipher pads 1944, X-2 Cryptographic File, Area E cipher
  courses) are not digitised and are training or own-traffic material.
- RG 126 Equatorial Islands 1938 coded radiograms: decoded interlinear on the draft. RG 128: Pearl Harbor machine
  intercepts. RG 41: 1918 film intertitles deleted as possible code. RG 46: Overman subcommittee 1920 telegrams filed
  with their code book. RG 23/56/57/392/25/224: telegraph-blank boilerplate. RG 472: Vietnam, out of period.
- Repeated noise: HOLC "code letter" area descriptions (RG 195), survey code books (RG 306, 307, 479, ...), Navy and
  Army crypto-aid admin files (RG 181, 313, 337, 338, 331, 319).
