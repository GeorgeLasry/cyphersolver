# NARA RG 59 bulk-scan triage, slice A: State Department 1789-1906 (27 Oct 2026)

Brief: `research/nara_reels/TRIAGE_BRIEF.md` and `research/archive_sweep_2026-10/BRIEF.md`. Input: the RG 59 hits of
`research/nara_reels/bulk_scan.py` (`out/rg_59.jsonl`, `out/agg_rg_59.tsv`). Slice: every RG 59 hit dated 1789-1906,
i.e. all publications except the decimal/numerical files (M862, M367, M1442, M973, T1249, M1284, M1286), the Polish
records (M1751), passport/internee series and anything whose dates start after 1906 (the 1906+ agent has those).

Output: `candidates.json` (5 rows, built by `rows.py`). Coverage per publication: table at the end (also
`coverage.tsv`).

## Method

1. `slice.py`: 23,423 hits in the slice (15,311 code-like frames, 8,089 phrase hits, 23 description hits) out of
   43,464 RG 59 hits, written to `slice.jsonl`.
2. `triage.py`: every frame classed from its OCR snippet (`frames.tsv`): table (statistical/money/form keywords,
   decimals, ascending runs) 4,833; code-like 687; mixed 1,690; prose 1,459; few numbers in the snippet 6,642. Year
   profile: genuine number-code runs exist only 1789-1840; from 1840 on, every frame of the `code` class checked
   (`code2.txt`, 321 items listed, the post-1845 ones read line by line) is a table, a register/index of despatch
   numbers, a newspaper or OCR noise. State Department telegrams after 1867 were sent in code words, not numbers,
   and survive in these volumes only as decoded "Telegram received in cipher" forms.
3. Phrase hits: 8,089. 337 are telegraph-blank boilerplate ("errors in cipher or obscure messages") and 5,762
   are "Telegram received/sent in cipher" form headings over decoded text (1867-1906); both dropped by pattern. The
   1,990 left (`phrase_keep2.json`) are "in cipher/cypher" mentions inside clear despatches ("I cabled you in
   cipher", "text of telegram (in cipher)"), checked by random samples per publication. The 47 remaining "could not decipher / undeciphered / key lost / not decypher" hits were read
   one by one: telegram garbles (1868-1906), illegible handwriting, a lost desk key, the 1867 code book's own word
   list, the Jameson Raid clipping (1898) and the 1827 Domestic Letters note on decipherments being bound with the
   originals. None is an undecoded document in RG 59.
4. Every item (reel/volume) dated before 1870 whose snippets showed 3-4 digit code groups (`code_items.json`, 85
   items before 1845) was fetched whole with `research/nara_reels/reels.py fetch` (one request per item, 4 s apart;
   OCR cached in `research/nara_reels/cache/`). `analyze.py` lists the code frames of each item, names the code by
   its signature groups (JQA/St Petersburg the=1385 of=1576 and=668 that=1384 I=1401; Armstrong the=972 of=1354;
   Pinckney the=1651 of=133 and=1343; Code No. 11 the=1196 of=1508) and decodes a frame with each repo key
   (`--decode`); `ciphergrep.py` greps an item's OCR for cypher/decypher/translation. A frame with as many OCR words as
   groups and readable words interleaved is an interlinear decipherment; a frame with near-zero words is pure code.
5. Four frame images viewed (M34-008-0015, M30-004-0244, M37-02-0093, M31-014-0039; kept only in the session
   scratchpad, not in the repo). Printed editions checked: Manning 1925 vols. 1-3 (archive.org text), Founders Online (via
   web search), web search for prior decipherments of each row.

## Best leads

1. **Delacroix → Létombe, Paris 25 Messidor an V (13 July 1797)**, a whole French ministerial despatch in a
   ~1,100-group code, copy sent home by Rufus King in his No. 53 (M30 vol. 5 fr. 0244-0245). Viewed: clean code, no
   decode. The French register copy (AMAE CP États-Unis) would give the plaintext, so external-plaintext key
   recovery is likely; otherwise a codebook attack on ~470 groups.
2. **William H. Crawford → Monroe, Paris 1813-14** (M34 vol. 17): thousands of groups in the code rebuilt in
   `targets/jqa`; the repo table already decodes phrases from the OCR. Decoded in 1813 but the decipherment is not on
   the film and no print was found. Solvability 5.
3. **Powhatan Ellis → Forsyth, Mexico 1836 and 1839** (M97 vols. 7-9): same code, pure code on the film, decodes
   readably ("a war with Texas ... will be decidedly popular"). Must first rule out Manning, Inter-American Affairs
   vol. 8 (not reachable: HathiTrust bot check).
4. **Anthony Morris → Monroe, Cadiz/Madrid 1813-15** (M31 vol. 12): ~3,000 groups in an unidentified syllabic code
   (285 and 76 the commonest groups), two copies of one despatch (fr. 0124-0125 and 0191-0192). Viewed: no decode.
5. **Poinsett, 14 June 1814** (M37 roll 2 fr. 0097-0099): a second coded Poinsett letter, sibling of the catalogued
   1813 Santiago despatch.

## Key leads (no new ciphertext row)

- **The JQA code is the Department's general code of 1803-1840.** Same signature groups and readable trial decodes
  with `targets/jqa/code_table.tsv` in Livingston/Monroe, Paris 1803 (M34 vol. 11 fr. 0014-0031, Louisiana), Crawford
  1813-14, Rush, London 1817-21 (M30 vols. 23-26, interlinear), Russia 1808-11, 1820, 1836 (M35 vols. 1, 8, 13),
  Madrid 1822-25 and 1840 (M31 vols. 22-25, 33), Poinsett's Mexico 1823-29 (M97 vols. 1-5), Colombia 1826-30 (T33
  roll 5 fr. 0140) and Ellis 1836-39. The interlinear pages (e.g. M30-019-0148, M35-08-0180, M35-13-0219,
  M31-033-0138) can fill the open values of the table.
- **John Graham, New Orleans, 2 Jan 1806**: T260 roll 8 (naId 221215877) frames 0008-0011, code with Jacob Wagner's
  interlinear decode. This is the sibling `targets/graham1806/NOTES.md` asks for; align it to get Graham's code and
  test the open groups of the 22 Nov 1806 extract.
- **1790s legation code** (frequent groups 1465, 663, 1518, 1490): interlinear decodes at M31 vol. 6 fr. 0018-0019
  (Madrid 1795), M43 vol. 4 fr. 0152 (Lisbon 1797-98), and Thomas Pinckney's "Explication of the Cyphers" for his
  23 Nov 1793 letter (M30 vol. 3 fr. 0179; code at 0135-0136, 0178, 0180, 0305).
- **XYZ envoys' code** (Pinckney, Marshall, Gerry, Paris 1797-98): M34 vol. 8 (naId 188669228) fr. 0015-0024,
  0098-0111, 0267-0276, pure code; plaintext printed in ASP Foreign Relations 2. A known-plaintext rebuild would give
  the code (unidentified family).
- **Barlow, Paris 1811-12** code: interlinear at M34 vol. 16 fr. 0011.
- **Codebooks of the Department of State, 1867-1876** (T1171, naId 417267710): the 1867 code digitised (key for the
  1867-76 cables, e.g. the catalogue's 1868 Vienna cable).

## Dead ends (counted)

- Tables and forms: 4,833 frames classed table; the remaining classes were checked by sample per publication and by
  the full-OCR pass for every pre-1845 code-like item. The post-1840 "code" frames are trade statistics, consular
  fee returns, despatch registers, gazettes, budget tables (M44 1886-1905), Hawaiian census tables (T30), etc.
- Code runs that are decoded or printed (not rows): Short 1789-90, Humphreys 1790-93, Carmichael/Short 1792-95, T.
  Pinckney 1793, King 1796-1800, Murray 1797-1801, W. L. Smith 1797-98, XYZ envoys 1797-98, JQA Berlin 1799-1801,
  Lear 1802, Livingston/Monroe 1803, Pinckney 1803-05, Armstrong 1804-10, Graham 1806, JQA Russia 1809-15, Barlow
  1811, Sumter 1813, Rush 1817-21, Russia 1820 and 1836, Poinsett Mexico 1825-29 (Manning), Colombia 1826-30
  (Manning), Madrid 1840.
- Phrase hits: 337 telegraph boilerplate, 5,762 decoded telegram headings, 1,990 in-text mentions (sampled), 47
  read individually (all garbles, handwriting, or decoded).

## Not reached / blockers

- Manning, *Inter-American Affairs* vol. 8 (Mexico 1831-48) and the later volumes: HathiTrust bot check; not on
  archive.org. Needed to clear the Ellis row.
- Weber, *United States Diplomatic Codes and Ciphers 1775-1938* (1979): not online; it lists the codes by period and
  would identify Morris's and the XYZ envoys' codes.
- Frames were judged from OCR for Crawford and Ellis (not viewed). The OCR of 1810s hands is noisy (h for 4, g for
  9), so transcriptions must come from the images.
- Items dated 1845-1869 were triaged from snippets only (no full-OCR fetch) because no numeric code appears in them.
