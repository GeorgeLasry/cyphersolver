# R9873 — the Duke of Sessa to Charles V, Rome, 14 April 1524 (RAH Salazar A-31 ff. 79-86), the reading

Rests on: the cipher transcription and line-by-line decode `r9873_cipher.txt` (pass 16, 2 Oct 2026; DECODE images
IMG_R9873_I46008_P1-P8), the key in `key_working.md` (passes 1-17) and the b23 re-read (23 Oct 2026,

triplicate with its contemporary deciphering (CSP 636, Gayangos MS) are not imaged anywhere found. Bergenroth's
English abstracts (CSP 636-638, `csp/csp2_636_638.txt`) were used as a topic check only, never as the source of a word.

The text runs in the order of the working file: the clear passages it quotes, and the cipher runs joined into
sentences, in the period spelling. Where the working file does not transcribe a clear passage, a line
"[clear text not transcribed]" stands for it.

Marks: `[?word]` partly carried (a tentative code value, or spelled letters that need one sign read as its look-alike
or one letter mended); `[word]` supplied, carried by nothing; `[…]` unread; `[…kam]` an open code group (the group
named after the ellipsis, so that it counts as a hole). Unbracketed words are carried by the figures with a code value
