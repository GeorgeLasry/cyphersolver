# Key for BnF fr. 15564 f. 78 (Guise to Mercœur cipher)

The base key is George Lasry's 2022 table for fr. 15564, as published on cryptiana GL.htm: `GL_BnFfr15564.png`
(in this folder; `key_top.png` and `key_bot.png` are crops of it). The values below were added in this project;
the list is copied verbatim from NOTES.md, Method, step 4.

Three sign-by-sign passes against native-resolution crops (subagent, logged in `f78_decipher.md`) added sign
values that are missing from or wider than Lasry's sheet: ɋ/ƀ = M, ɛ = F, ≈ʃ = P, the R shape = B, :: = H,
∽ = G, ∩ = Y, and ʃʃɤ = MON, ʃbn = NOUS, gb = MONSIEUR, g2 = DUC.
