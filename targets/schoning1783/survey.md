# schoning1783 scan survey (KHA A32-603)

Cipher types seen: (a) a symbol cipher (letter-for-sign alphabet, written as runs of hooks/strokes) mixed with underlined
3-digit code numbers, in Schöning's own early letters (Aug 1783, numbered No. 1-6); (b) plain-hand letters with 2-3 digit
code numbers (e.g. 857 = S.M., 809/818 = le Roi, 446/450 = Hertzberg, 914 = Thulemeier, 66 = Altesse, 70 = Altesse
Sérénissime, 862 = Schöning) glossed between the lines.

## Correction / cipher summary

The cipher is two-layer: a **symbol alphabet** (hooks/strokes, letter-for-letter, word-separated) for running text, plus
**2-3 digit code numbers** followed by `:;.` for names (61, 65, 66, 69, 70, 857, 880, 446, 191, 343 ...). Symbol runs are
only rarely glossed on the originals; the decipherer's separate copies write the symbol text out but leave the code
numbers as numbers. Codes are almost never glossed. (Rows s007-s013 above said "numbers glossed"; they are the No. 4
material where a contemporary hand interlined some text; treat them as partly glossed.)
