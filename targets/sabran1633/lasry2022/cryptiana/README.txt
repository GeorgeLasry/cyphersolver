index.html is fully self-contained (styles and images embedded): open it directly. It holds the write-up with all 18 letters and the 43 readings by image.
For insertion in a host page: insert entry.html (write-up and letters) and readings.html's <section> (readings by image), include entry.css once, and copy images/ alongside.
CSS is scoped to .sabran-entry; IDs start sabran1633.
Bold = written in cipher in the manuscript; regular = written in clear. [France?] etc. = code signs (? = tentative); [?] = unreadable; word[?] = doubtful.
Please render the Markdown files (READING.md, READINGS_BY_IMAGE.md, readings/*.md) as Markdown, not as plain text: the bold is part of the reading.
