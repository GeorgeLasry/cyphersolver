# Dana to Livingston, St Petersburg, 6 Apr 1783 (O.S.), No. 23: the eight cipher lines as sentences
# Word division and punctuation are ours. [29], [31], [137], [168] are code groups whose meaning is not known.
# Letters in square brackets inside a word (i[s], [o]r, me[a]sure, [m]ay, in[f]luence, proper[l]y, he[n]ce) are
# completed from a number cut at the frame edge or supplied at a line end (see decryption.txt and NOTES.md).
# The opening "[29]n an [31]" is not confirmed: n, a, n decode directly, but the code groups move the key phase
# irregularly (see NOTES.md, section 3), so how these letters join the groups is open.
# The plaintext is English, so no translation is given. Spelling normalised: Dana writes "irresistable".

[29]n an [31] like this, which i[s] not guided by any settled principles [o]r system, you can be certain of no me[a]sure.

What the [137] adopt in this hour [m]ay be opposed by an irresistible in[f]luence in the next.

In short, proper[l]y speaking, there is no [168] here.

He[n]ce my present difficulty.
