## Primary sources (not in this repository)
- **BnF, Baluze 103** (Affaires de Catalogne — Correspondance de Marca), Gallica ark:/12148/btv1b9001389d
  - view 111: f. 50r (20 cipher lines). https://gallica.bnf.fr/ark:/12148/btv1b9001389d/f111.item
  - view 112: f. 50v (12 cipher lines)
  - views 366, 368: f. 171r (cipher) and f. 172r (period decipherment), used for the calibration
  - views 486, 490: f. 230r (cipher) and f. 232r (period decipherment), used to check the key
  - views 402, 424, 487: f. 189r, f. 200r, f. 230v, used to check the code groups

Images are not redistributed; refer to them by view number. Source gallica.bnf.fr / BnF.

## Key
- Satoshi Tomokiyo, Cryptiana, code/louisxiv0.htm, "Le Tellier-Marca Cipher (1644)" (Last-Modified 2025-12-06): « Le Tellier's letters use the following cipher in April to October 1644 (f.50 (undeciphered), f.171, f.189, f.200, f.230 (deciphered on separate pages)) ». The table image louisxiv_0marca1644.png is not included; values in `data/key.tsv` whose source includes T are that table rewritten with sign names.
