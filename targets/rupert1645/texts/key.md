# Key for R4921 (Charles I to Prince Rupert, 29 April 1645)

The key is George Lasry's King-Queen key "TNA SP106-5", reconstructed in 2020 and filed on DECODE record R929
(SP 106/10 f. 247), applied unchanged with `apply.py <key file>`. His key file is downloaded from DECODE into the
git-ignored `decode/` folder and is not in the repository.
