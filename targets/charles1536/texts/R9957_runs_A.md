## Key notes (fork A)

Values met on 0001-0006, each holding at every occurrence there:
- e+ (te) is drawn like a hooked 4 (ꝗ), distinct from ꝝ (crossed 4, a): run 1 "adelante y se tenga", run 4 "este",
  run 9 "este alli", run 12 "gasten", runs 16-18 throughout.
- ŧ̲ (ma) is a t whose bar runs long and can look like ŧ+: run 1 "manera", "demas"; run 5 "mandado"; run 12 "mas".
- The nn-sign of the key (Luo's "-9") stands for ñ, drawn ꝛ / ɉ, with f for ño or ꝝ for ña: año (run 4), Señora
  (runs 5, 12, 16), Cataluña, Perpiñan (runs 5, 6, 12, 18), compañias (run 7), Cañete (run 12), daño (runs 16-19).
- bi = n̲ (runs 1, 5, 16: abierta, apercebimientos, bien); bu = np (runs 12, 17: busque, buelvan); ba = 2ɥ (run 4,
  abaxo); ple = +0 (run 16, plega); plo = 90 (run 12, Pamplona): all as Luo's table.
- Letter f = B (looped b): Francia, frontera (run 18). Letter m also = the number 7 (compañias, run 7).
- 28 (rr) is used for initial r: rresolutos, rreynos, rresidir, rrecaudo (runs 4, 5, 7, 11, 17).
- Dotted signs are nulls (key rule): two dotted a in run 5; the dotted "de cavallo" in run 8; a dotted a after the code
  sign in run 11.
- "a P" (el) is often written joined and looks like ap (do); context decides (runs 11, 16, 17, 18).
- 52 in "dineros/dinero" (runs 15, 16) where the key's ne is 53: not adopted as a key change (two occurrences in one
  word only); kept as [?ne].
No key value was changed.
