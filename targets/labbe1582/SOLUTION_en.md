# L'Abbé to Nevers, 1577 (BnF français 3198 nos. 30, 37-38): English translation of the deciphered insertions

Translation (Claude Opus 5.5, 23 Oct 2026) of `SOLUTION.txt` (AngusRobinson's decipherment, PR #20): the cipher in
these letters is short insertions inside clear French, and each is translated here as a phrase, run by run, with the
run labels of SOLUTION.txt. The clear text round them is not transcribed in the repository (outlined in
`prague_reading.md` and `breslau_reading.md`), so the phrases stand alone. Same marks: `[x]` letters restored from
context, `[words]` a run restored from context. Names as decoded (uuarsauicio = Warszewicki?, sboroschi = Zborowski,
le uueber et le trautzen = Weber and Trautson, batori = Báthory).
