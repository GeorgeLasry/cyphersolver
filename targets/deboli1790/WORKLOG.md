# deboli1790 work log

- 2026-10-26 access: ZbPop 4 letter list (agad.gov.pl/inwentarze/ZbPop4.xml) and scans on agadd2: 109 despatches, 469 images. Viewed k. 2-4 (2 Jan): code groups only, French heading and "Sire!", no interlinear decipherment.
- 2026-10-26 access: key volumes ZbPop 444, 451, 453, 454 and the deciphered register ZbPop 320 have no album on agadd2 and no letter list (404). Not reachable online.
- 2026-10-26 access: thumbnails of the five scanned cipher volumes (ZbPop 428, 17, 4, 5, 416) fetched and scanned as contact sheets: code groups throughout, no decipherment pages.
- 2026-10-26 literature: web search for a printed 1790 decipherment found none. Zielińska & Danilczyk, Deboli 1782 (IH PAN 2017, RCIN, read in the browser): the cabinet kept deciphered copies ("deszyfry") of Deboli's despatches (AKP 265 for 1782-83). The French cipher came first; a Polish cipher was added in 1781.
- 2026-10-26 literature: Rolnik 2025 (Rocznik Filozoficzny Ignatianum) cites Deboli's 1790-92 letters from ZbPop 415/420/421 and says this correspondence was in cipher. It quotes Polish text from ZP 420.
- 2026-10-27 hypothesis: ZbPop 420 holds the cabinet decipherments of ZbPop 4. Matching the letter lists by date, 99 of 109 cipher despatches have a same-date Deboli item in ZbPop 420. The other 10 (2 Jan-2 Feb) are at the end of ZbPop 417 (k. 353-386). All 109 are matched.
- 2026-10-27 verification: 9 Feb pair (ZbPop 4 k. 34r / ZbPop 420 p. 13). Same heading and "reçu le 20". 1559 stands at words "W" (1) and "w" (Warszawie); 606 at both "z" (okazyi, strony); 1092 opens "poważeniu".
- 2026-10-27 verification: 2 Jan pair (ZbPop 4 k. 2r / ZbPop 417 k. 353). Same heading and "reçu le 13". 1559 = "W" (word 1) and "w" (samey); 1092 opens "pomiędzy". Code is Polish, syllables and words.
- 2026-10-27 verification: image counts per despatch correlate (r = 0.69 over the 92 King-addressed pairs; 409 cipher images against 400 clear).
- 2026-10-27 verification: 16 July pair, one of the 17 that AGAD lists as Deboli to Kiciński. The clear text is headed "Sire!" with the same date and "reçu le 27". It is the King's copy, so the inventory's addressee is wrong. Content (Nassau-Siegen's losses, the frigate Katarzyna) fits July 1790.
- 2026-10-27 sibling check (dates only): ZbPop 428 (1788) pairs with ZbPop 417, 108/111. ZbPop 17 (1789) pairs with ZbPop 419 (+3 in 417), 103/106. ZbPop 5 (1791) pairs with ZbPop 421, 98/105. Not checked by alignment.
- 2026-10-27 outcome: deciphered at the time; method "read from existing decipherment". No key rebuilt, and the code groups were not decoded beyond the three equivalences above.
