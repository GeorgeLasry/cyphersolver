# Postal censorship and German espionage: codes and ciphers file, 2 Nov 1917 (Unsolved Catalogue no. 671)

Status: no write-up. Blocked on access: RG 457 NR 4458 (naId 2811219) is not digitised.

Blocked on images: the file is not digitised and has to be ordered from NARA College Park. Nothing below rests
on a sight of the file.

## The document

- NARA RG 457 (NSA/CSS), series Historic Cryptographic Records (naId 2765793), file unit "NR 4458 ZEMA20 4895A
  19171102 Censorship and German Espionage-Codes and Ciphers" (naId 2811219).
- Textual records, paper, container 1393; National Archives at College Park, Textual Reference
  (Archives2reference@nara.gov). Access and use unrestricted. Extent not given in the description.
- Neighbouring NR numbers in the same ZEMA20 box are unrelated (NR 4454 German Army code in Norway 1944; NR 4455
  *Deadly Magic* 1978; NR 4456 Code M procedure 1940; NR 4457 German naval ciphers 1944, the RIP 401 scan on
  cryptocellar.org). Nothing in the box ties NR 4458 to a sibling.
- Correspondents, place and language are not in the description; "German agents in the US and Mexico" is the
  catalogue's presumption. The date (2 Nov 1917) fits the moment postal censorship began passing suspect letters
  to MI-8 (October 1917, per the NSA *Brief History of U.S. Cryptologic Operations*). The title can also be read as
  a report or guide for censors on codes and ciphers rather than a file of intercepts: which it is is unknown.
