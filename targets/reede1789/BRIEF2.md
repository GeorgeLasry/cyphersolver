# Brief 2: transcribe Van Reede's cipher runs on pages WITHOUT a full decipherment (1789-91)

Same folder, fetching, notation and mark conventions as BRIEF.md (read it first). These pages were flagged as
"numbers in text": cipher runs inside French letters to Princess Wilhelmina, mostly with no decipherment above.

For each run write:

    # id <id> run <k>
    BEFORE: <the clear words just before the run, up to about 8 words, ASCII>
    CT: <groups in notation, marks included>
    AFTER: <the clear words just after the run, up to about 8 words>
    PT: <a decipherment written over the run if there is one, else: none>

Do not try to decipher. Append each block as soon as done. If a page has no cipher after all, write
`# id <id> NO CIPHER`. ASCII only. Final reply: pages, runs, groups, and pages that turned out glossed.
