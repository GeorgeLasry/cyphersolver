# US minister at Vienna -> Secretary of State, cable in the 1867 State Department code (catalogue 634)

Status: no write-up (attempted and closed: no ciphertext, no full codebook; nothing to publish)

## What the document is
One telegram, c. 1867-1873, from the US minister at Vienna (Watts or Jay) to Washington, sent in the 1867
State Department code with the code letters run together. John Haswell to Fish, 8 Jul 1873 (Fish Papers reel 95),
quoted in Weber, Masked Dispatches pp. 106, 131: 'the latter one was never deciphered'.

## State on 27 Oct 2026
- The telegram itself is not located: Weber gives no date, sender, length or archive item for it
  (Masked Dispatches pp. 106, 131 and ch. 18, text read from the govinfo PDF, 222 pp.; notes 4-5 cite Haswell to
  Fish 8 Jul 1873, Fish Papers roll 95, and RG 59 E 209 Telegrams sent, for other 1867-code telegrams).
- Weber p. 106 says only: first coded message from Turkey was one long string, decrypted by an assistant clerk;
  similar ones from Paris and one from Vienna, 'the latter one was never decoded'. p. 131 'probably never decrypted'.
- The 1867 code is NOT printed in full in the book. Ch. 18 (pp. 134-138) shows only a sample page: a one-letter
  substitution table for words not in the list, the 23 commonest words as single letters, and some two-letter words.
  The codebook was word/phrase code in the Stager style (names for dates, rivers for months, flowers for years).
  Without the full codebook, run-together letters cannot be split or read even if the telegram turns up.
- Two web searches found no printed decipherment of the Vienna telegram.

## Result
Not solved (outcome: not solved; extent none). Blocked from outside on two counts: no ciphertext, no complete key.
