Labels are arbitrary; a `?` after a label means the reading is uncertain.

| Label | Description |
|---|---|
| `0`–`9`, `10` | figures; `10` is written as one unit and counted as one sign |
| `o` | small raised o, distinct from figure `0` (`O`) |
| `O` | full-size o / zero |
| `8/` | 8 struck through with a stroke |
| `6^` | 6 with a hook or cap over it |
| `SQ` | square ◻ |
| `TRI` | triangle Δ |
| `C` | open bracket ⊏ |
| `T` | ⊥ |
| `T+` | ⊥ with a small cross above |
| `M` | barred m / ⊓ (m with a bar over it) |
| `P+` | p with a cross-stroke on the descender (ꝑ-like) |
| `DC` | vertical with two crossbars (‡) |
| `#` | double hash (two verticals, two crossbars) |
| `+` | plain cross |
| `A@` | a in a circle (ⓐ) |
| `X` | bold x |
| `Z` | 3-like z (ʒ) |
| `z` | plain z |
| `z-` | z with a bar (ƶ-like) |
| `ZX` | z with a long crossed descender (line 1, third sign) |
| `Y` | hooked y (ʏ) |
| `U` | small cup ‿ |
| `V` | small v |
| `L` | ⊢ (vertical with a short bar to the right) |
| `q` | q-like sign |
| `4/` | 4 with a slash |
| `al` | alpha-like ∝ / α |
| `dz` | d or a with a z-like tail (ʤ-like) |
| `e3` | ɛ-like sign |
| `phi` | φ-like sign |
| `f` | f with a crossbar (ƒ) |
| `LAM` | Λ |
| `=` | two horizontal strokes |
| `∴` | three dots; `:` / `·:` two dots |
| `/` | short vertical stroke between signs, probably a **word divider** (not counted as a sign) |
| `///` | three oblique hairlines, probably a **repeat or doubling mark** or a null |
