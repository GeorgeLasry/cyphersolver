# Lovell's key-letter sheet, PCC item 59 vol. 1 p. 144 (digital object 115, Fold3 file 172707):

# Colour exhibit photograph of the same sheet: NARA naId 2450021 ("Ciphers Belonging to the Various American
# Peace Commissioners"), image 1; its image 2 is the endorsement on p. 146: "Cyphers / Adams / H Laurens /
# Franklin / Palfrey / Jay".
#
# System (James Lovell's): alphabet of 27 signs, a..z and &. Each key letter heads a column that runs through the
# alphabet starting from that letter: row 1 = the key letter, row 2 = the next letter, ... row 27 = the letter
# before it. A plaintext letter is written as its row number in the column in use; the columns are used in turn,
# letter by letter. Rows 28, 29 and 30 are numbered on the sheet but carry no letters (nulls).
#
