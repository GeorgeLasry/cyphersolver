## The line in clear

> Make this addition to your cypher: be, 600; ce, 601; de, 602; fe, 603; ge, 604; he, 605.

Each pair is spelled in the code letter by letter: b, c, d, f, g, h followed by e (226). It gives each
consonant + e syllable a single new group. The printed Thomson form has no entry for any of these six syllables
(it has *bea, been, bes, ca, ch, ci, den, dent, fel, fen, fer, ger, head, hear, hence, her*, but no bare *be, ce,
de, fe, ge, he*). The addition fills that gap.

So the edition's note 7, "six symbols for syllables ending in r", is wrong. The syllables end in *e*. The
r-syllables *ar, er, ir, or, ur* already have their own entries in the printed form (76, 86, 150, 382, 331 in
Jay's copy).
