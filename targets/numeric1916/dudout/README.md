# N01 and N09, Brice Dudout (28 Oct 2026)

Two more numeric telegrams of June 1916, reported by email on 23 Oct 2026 (your NOTES: "New: N09 乾密 ..., and N01").

- `gaimusho/` — **N01**: Shanghai → Tokyo (青山南町三ノ五三), May 1916; an appeal from the Shanghai friends to Huang Xing. No prefix. The key is given by two decipherment tables on 外務省 paper kept in the same file (JACAR B03050089200, PDF 16, June 1916): it is identical to the key our search had found without them (see the method) .
  Site: https://bdudout.github.io/wenmi/en/method.html#gaimusho
- `qianmi/` — **N09 乾密**: Tokyo (青山南町三ノ五三) → Shanghai, 6–9 June 1916; Huang Xing. Renumbered “明密” book: page = written page − 11, columns and rows permuted. Key model: S. Tomokiyo’s idea (Cryptiana) ; key recovered in October 2026 (see the Qianmi page and the method).
  Site: https://bdudout.github.io/wenmi/en/qianmi.html (with Satoshi Tomokiyo's model, credited there).

Each sub-folder: transcription (digit groups), decryption (code by code), Chinese reading, English translation.
The 16 telegrams of the same file sent in plain standard telegraph code are in `../../ctcplain1913/`.
