# Catalogue 678. Communist Party of America book code, letters seized at 170 Bleecker St., New York, 1920-21.
# NARA RG 65, M1085 roll 940, case 202600 (4 of 4), naId 369272950. Pages are PDF pages of M1085-940A (A) and
# M1085-940B (B), e.g. A0015 = 940A p. 15. "scan 115" is the Bureau's own pencilled exhibit number.
#
# Every coded run found on the typed pages, as typed by the Bureau of Investigation's copyist. Read from the scans
# and re-read independently by a second agent; the redo re-read A887 runs (2) and (3) and the A886 member run.
#
# Format: one run per line:  <run id> TAB <key: new | old> TAB <tokens>
#   a/b     line a, letter b of the key page
#   -       a word break as typed ("--" is written "-")
#   {..}    clear text typed inside the run
#   [cut]   the page is torn or cut here; a token may be lost
#   [cut]1  a token cut at the edge, only its last figure visible
#   ?/16    a token with an unreadable figure
# Lines starting with "##" give the page, date, writer and the clear words around each run (">" lines).
# The Bureau's own "Decode:" lines are in bureau_decodes.tsv, not here.
