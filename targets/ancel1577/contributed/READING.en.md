# Reading of the undeciphered cipher passages in BnF Cinq Cents de Colbert 398

Each table gives, per manuscript line: the key's output on the adjudicated transcription
(`data/transcription/<page>.txt` → `data/decoded/<page>.txt`), and a word-divided reading.
In the key output, CAPITALS mark symbols flagged as uncertain in the transcription, `[..]` are
double letters or nomenclature (`[que]` = plus, `[est]` = ucl, `[pour]` = ros), `{..}` are
plain-letter groups (code words or nulls), `·` an unreadable symbol.

Marks in the reading column:
- ◎ the key output reads as words without change
- ○ one or two symbols corrected from context (mostly ∂/δ = i/n, 9/q = d/l, oc/4 = o/a); see the output column
- △ larger conjecture, unreadable symbols, or unclear syntax
- [..] code word; a meaning is given only where the context or a deciphered letter supports it (see OPEN.en.md)

Orthography is kept (u/v and i/j as in the key, which has no j or v). Accents and punctuation are added
only where needed to read.
