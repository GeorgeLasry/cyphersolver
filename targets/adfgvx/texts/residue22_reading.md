# Childs residue, the nine messages read in full: reading

Rests on: the 2017 Cipherbrain readers' decryptions (Armin, Norbert, Lasry, Baertl; Schmeh's blog thread), consolidated
per Childs page in `residue22_decryption.md` (the table, which also lists the thirteen open and partial messages). This
file keeps only the nine messages read in full, so that the reading body is the running text and not the table (v3
verification, 23 Oct 2026). Letters as the 2017 readers give them; the operator's X (stop) is rendered as a full stop
or comma, nothing else changed; abbreviations (DIV, TELEGR, NR, FEINDL, ASO, OHL, VERBDG) kept as sent. The partial
messages (pp. 164 F-G-X, 164 VFGAG, 215 VGADA) are in `vgada_partial_reading.md` and the table; they are not part of
this entry.
