## Wells 2015 (purchased, kept local)

B. K. Wells, *The Archaeology and Epigraphy of Indus Writing* (Archaeopress, 2015), PDF bought by D. Bourdeau 26 Oct
2026; `wells2015_archaeology_epigraphy.pdf` and its text `wells2015.txt` are git-ignored (licensed copy, not for
redistribution). Numbering close to ICIT (763, 489, 821 differ). Contents used: ch. 4 volume system (700 + long strokes,
one long stroke about 40.4 litres from three measured jars H-370 / H-371 / H-372; not extendable, no pot dimensions in
the ICIT records); ch. 5 numerals (linear vs stacked strokes count different signs, pp. 69-70: prior work for set 552);
ch. 6 proposed values (Fig. 6.20) and Proto-Dravidian verb endings (Fig. 6.21), tested as set 641 (not supported).
No object-by-object tablet catalogue is printed (counts by type and mound only, Fig. 4.3-4.4).
