# Key: Filippo Maria Visconti's second cipher with Francesco Sforza (DECODE R5324)

Source: ASMi, Carteggio Visconteo-Sforzesco, cart. 1597 no. 24, DECODE **R5324** ("Carteggio_Sforzesco_scat._n.1597_24",
key record, status N/A, dated only 1450-1555, no sender or receiver). An 18th-century fair copy headed "Filippo Maria Duca
di Milano". The image is fetched with `targets/visconti1446/fetch_keys.py 5324 5324` (git-ignored, in
`targets/visconti1446/img/keys/`). The Duke's other key, cart. 1597 no. 23 = R5323, reads the rest of his 1446-47 slips
(`targets/visconti1446/key.md`); it does not fit f. 15.

On the slip ꝺ serves a, c and o, and ꝺ̸ is r; context decides. ♀ with a bar is et, but the similar 4 is i and ꝑ with a
bar is s.

Word signs: et = q with crossed tail ; que = -c ; qui = ʒf ; in = com ; de = cul ; con = ∵ ; qua = ɔ- ; da = cam ;
che = caz. The right-hand block of the copy is written cipher above plain: cim = per, cet = come, cib = ciò, bb = ss,
pp = mm, fo = di; ggf = ff.
