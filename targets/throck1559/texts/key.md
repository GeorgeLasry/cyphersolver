The base key is Tomokiyo's Cipher 1 key image attached to the DECODE record R2988 (`DOC_2988_*.png`, kept with the
git-ignored images in the main checkout `targets/wod1568/img/`); it is not transcribed in this folder. What this

From NOTES.md: "the whole block decrypts with Tomokiyo's key after these corrections: x and υ = i; y = f/h; z = m;
ρ = d/t; ∫t = w; Q = *be*; ξ = *your Majesty*; a dot over a sign marks a code word." Pass 3: "Key additions: flat-topped
6 = w; ζ = null inside words; q̇ = your Majesty; K = all(?). Twelve code signs are still open (1k̲ ρ̲ g̲ δ̄ δ̲ ō ⊓̄ q̄ r̄ π̄ ƒ̇ ʋ̲)."

From main_decrypt.txt, pass 2:
Key corrections: x and υ = i; y = f or h; z = m; ρ = d or t (context); ∫t = w; Q = <be>; ξ = <your/Queen's Majesty>.

Pass 3:
Key additions: G (6 with a flat top, distinct from 6) = w (G⊓⊥ who, G⊓v when/whe-); but 6/G confused in 'accepted' (a).
 q (looks like 9) = u (sundry, service, Julii). ζ = null inside words (ge-ζ-ntleman), else 'the'/null.
 K (capital) = code, probably 'all' (wealth and K felicitie). q̇ (dotted) = your Majesty (when q̇ perceive; please q̇ to give credit).
 T and ; = x, p (experience). δδ doubled = nulls. Crop overlaps duplicate 1-3 signs at third boundaries (ignore repeats).
