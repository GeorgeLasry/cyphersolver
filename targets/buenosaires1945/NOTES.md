# Code messages found in the ex-German Embassy archives, Buenos Aires, report of 16 June 1945 (Unsolved Catalogue no. 663)

Status: no write-up. Blocked on access: neither NR 2054 (naId 2808583) nor the related NR 1403 (naId 2807843) is digitised.

Blocked on images: no ciphertext is available. Nothing below rests on a sight of a message.

## The document

- NARA RG 457, Historic Cryptographic Collection, NR 2054 (box CBLK11, 158A), "Information on Code Messages Found in
  Ex-German Embassy Archives - Argentina", 16 June 1945, file unit naId 2808583
  (https://catalog.archives.gov/id/2808583). Catalogue record only: no scope note, no digital objects (checked
  27 Oct 2026 through the catalog proxy API).
- Related: NR 1403 (box CBKG76, 10933A), "German Clandestine Radio Code Messages and Axis Agents in Argentina",
  29 Aug 1944, naId 2807843 (https://catalog.archives.gov/id/2807843). Also no digital objects.
- What the report holds is unknown: it may be code messages (ciphertexts) found in the embassy files after Argentina
  broke with Germany (Jan 1944) and declared war (27 Mar 1945), or only a covering report about them. Whether it
  carries ciphertext at all, and whether the messages were read, is not stated in the catalogue.
