# Camus label legend (sign shapes)

Michael Brackx, issue #91 comment of 23 Oct 2026 (verbatim).

One label set for every Camus leaf. It replaces the three first-round label sets (a: ff. 111–112; b: ff. 132, 134;
c: ff. 151, 272). `?x` = a sign with no value yet (read as unknown);
`+` = null.
