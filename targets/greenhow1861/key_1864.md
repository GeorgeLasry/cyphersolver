# Key used: the 1864 Greenhow key (NARA M1091, naId 62017285, image 0484)

Source: NARA RG 45, M1091 Subject File of the Confederate States Navy, file "DC - Codes and cryptography -
Miscellaneous", naId 62017285, image 0484 (image 0485 is a photostat of the same sheet):
<https://catalog.archives.gov/id/62017285>.

- Header of the copy: **"Lamb Papers CXXIX. Copied A. H. L."** (last initial uncertain; "A. H. S." is possible), with
  "D C" written above. Not "Pickett Papers XXIX", as a first reading had it.
- Docket: "This paper was found on the person of Mrs Rose O. Greenhow, who was drowned in trying to land from the Br.
  S.S. Condor off Fort Fisher, 1864".
- Image 0483 is a different table ("Confederate cipher 1864", white on black, A = <, B = ^ ...). It does not apply.

The key was read from the left column of image 0484 by two agents independently; the readings agree. In the 1861
letters the same letters are written in a freer hand; the "letter form" column says how.

The sheet also has digraph signs (th, ph, sh, st, oo, ie, ch, un, on, ei, ss), code signs (Thousand, Hundred, House,
Horses, Men, Officers, Capitol, Street, Cannon, Lincoln, Infantry, Penn. Avenue, Regiment, Washington, Richmond,
Virginia, S. Carolina, Soldiers), figures, and the rule "Double letter: 2d letter itself inverted". None of the code
signs was identified on side 1.
