and for B (and the torn start of C) on the Claro's surviving half-lines **plus** the intact cipher block of f. 31v (8 lines) and the f. 33r block of C (5 lines), transcribed here

from the figures, with the code groups and signs listed in `R9487_reread_log.md`. `[xad]` = a code group with no
value; `[?word]` = a word partly carried (one sign or code uncertain); `[…]` = unread or torn. Spelling as written.

## Reading
