05 Our check

This result is George Lasry’s. This project did not re-solve the cipher: it checked one sample against the Gallica image and recorded what it found.

  • Batch A. Image checked: https://gallica.bnf.fr/ark:/12148/btv1b100387843/f83.item
  • Folio matches the report: yes; cipher present: yes
  • What we checked: f89r "Post data ... Signore" cipher postscript dated 28 Jun 1452, signed Nicodemus; facing f88v carries the contemporary decipherment (clear: "vescovo de Novara ... la V. Ill. hauria ben facto ... paragonata ... Certificandone Signore"), which matches the clear islands on f89r and his contents; no symbol-level decode of a run done
  • Verdict: partly confirmed (method read from existing decipherment, extent partial). The check is a sample, not a re-solution.
  • Notes: A literal 15th-c. decipherment sits on f88r-v next to the cipher, and the key is Domnina 2018s reconstruction, so little is new beyond alignment. Transcription incomplete; status Partly deciphered.

No reading held here (checked 23 October 2026). Unlike Lasry’s other entries, the extract of his report in this repository carries only the metadata of his report page: no excerpt, transcription or decryption of the postscript. So no text of it is held here, and the entry counts as decoded, not read until one is. The way to it is the contemporary literal decipherment on f. 88r (lower half, “Post dat. Signore …”) and f. 88v (Gallica btv1b100387843, views 82–83, opened on 23 October 2026): about thirty lines of abbreviated fifteenth-century cursive, to be transcribed and aligned with the cipher on f. 89r. The result remains Lasry’s.
